# 研习簿

一个个人学习记录网站，用于记录每日学习内容与 1–5 分投入强度，并按项目查看今日、本周、历史记录和近 12 周学习热度。

## 功能

- 使用 ChatGPT 账号登录
- 新增、编辑和删除学习记录
- 使用 1–5 分记录学习强度
- 创建、编辑和删除学习项目，并设置目标、状态与计划日期
- 将学习记录归入项目并按项目筛选
- 今日与本周平均强度统计
- 当前与最长连续学习天数
- 近 14 天学习强度趋势图
- 可分页加载全部数据的历史记录搜索与项目筛选
- 可按项目筛选、点击查看当天明细的近 12 周学习热度表
- 桌面端和移动端自适应界面

## 本地开发

```bash
npm install
npm run dev
```

默认访问地址为 `http://localhost:5173`。

## 构建

```bash
npm run build
```

项目使用 Next.js、Vinext、Cloudflare D1 和 Drizzle 构建。
