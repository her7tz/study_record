# 研习簿

一个个人学习记录网站，用于记录每日学习内容与 1–5 分投入强度。同一天的多条记录会累加强度，并按项目查看今日、本周、历史记录和当月学习热度。

## 功能

- 使用 ChatGPT 账号登录
- 新增、编辑和删除学习记录
- 使用 1–5 分记录学习强度
- 创建、编辑和删除学习项目，并设置目标、状态与计划日期
- 按完成状态分类项目，支持自主、时间和重要度排序
- 为项目设置 1–5 重要度，按“重要度 × 强度”计算积分
- 完成项目时获得与项目重要度相同的学分
- 将学习记录归入项目并按项目筛选
- 今日、本周与历史累计强度统计
- 当前与最长连续学习天数
- 近 14 天积分趋势图，点击数据点查看积分来源
- 点击本周或累计积分查看按项目的积分分布
- 可分页加载全部数据的历史记录搜索与项目筛选
- 导出完整 CSV 记录和 JSON 备份
- 可切换年月、按项目筛选、点击查看当天明细的当月学习热度表
- 桌面端和移动端自适应界面

## 本地开发

```bash
npm install
npm run dev
```

默认访问地址为 `http://localhost:5173`。

## 构建

```bash
npm run build
```

项目使用 Next.js、Vinext、Cloudflare D1 和 Drizzle 构建。
