# 研习簿

一个个人学习记录网站，用于记录每日学习内容和时长，并查看今日、本周统计、历史记录与近 12 周学习热度。

## 功能

- 使用 ChatGPT 账号登录
- 新增、编辑和删除学习记录
- 今日与本周学习统计
- 历史记录搜索
- 近 12 周学习热度表
- 桌面端和移动端自适应界面

## 本地开发

```bash
npm install
npm run dev
```

默认访问地址为 `http://localhost:5173`。

## 构建

```bash
npm run build
```

项目使用 Next.js、Vinext、Cloudflare D1 和 Drizzle 构建。
