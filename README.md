# 研习簿

一个个人学习记录网站，用于记录每日学习内容与 1–5 分投入强度。同一天的多条记录会累加强度，并按项目查看今日、本周、历史记录和当月学习热度。

## 功能

- 使用 ChatGPT 账号登录
- 新增、编辑和删除学习／实验记录；历史记录按类型并排展示、分别按日期倒序分页
- 记录和项目删除后保留 7 天恢复期，误删项目时会一并保留关联记录
- 学习强度为 1–5 分，实验强度为正整数，不设业务上限
- 待做实验总目录按项目顺序汇总，仅显示待做项
- 完成实验自动生成历史记录并按“重要度 × 强度”计分，重复完成不重复记账；改回待做撤回积分，删除和恢复同步历史记录
- 升级时为已有已完成实验补入历史记录与积分
- 创建、编辑和删除学习项目，并设置目标、状态与计划日期
- 按完成状态分类项目，支持自主、时间和重要度排序
- 为项目设置 1–5 重要度，按“重要度 × 强度”计算积分
- 完成项目时获得与项目重要度相同的学分
- 将学习记录归入项目并按项目筛选
- 今日、本周与历史累计强度统计
- 当前与最长连续学习天数
- 近 14 天积分／强度趋势切换，点击数据点查看来源
- 点击本周或累计积分查看按项目的积分分布
- 积分兑换可超出余额，负余额随新增积分抵扣；兑换记录支持修改、删除和 7 天内恢复，余额与导出同步更新
- 可分页加载全部数据的历史记录搜索与项目筛选
- 导出完整 CSV 记录和 JSON 备份
- 可切换年月、按项目筛选、点击查看当天明细的当月学习热度表
- 桌面端和移动端自适应界面

## 本地开发

```bash
npm install
npm run dev
```

默认访问地址为 `http://localhost:5173`。

## 构建

```bash
npm run build
```

项目使用 Next.js、Vinext、Cloudflare D1 和 Drizzle 构建。
