# 本周任务

网站首页默认打开“本周任务”。按上海日期划分周次，周一至周日；可选择日期或前后切换周次，也可回到本周。

任务包含内容、选填备注和标记（待做、打勾、打叉）。再次点击当前选中的勾或叉恢复待做。标记单独保存，刷新页面后保留；修改标记不会覆盖任务内容或备注。任务不自动重复、不发提醒、不生成学习记录，不参与积分、强度、学分、连续天数或热度统计。

添加、编辑、标记和删除使用浏览器的 ChatGPT 登录身份，各账户数据隔离。删除后可在历史记录的回收站中恢复，期限为 7 天，恢复保留原标记。

实现：`components/weekly-tasks.tsx` 为独立首页模块；`lib/weekly-task-model.ts` 包含模型与校验；`lib/weekly-tasks.ts` 负责用户隔离的持久化操作；`/api/weekly-tasks` 提供 GET、POST、PATCH、DELETE。PATCH 支持仅提交 id、status 修改标记。既有 Agent 只读授权范围不变。
